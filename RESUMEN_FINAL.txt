  🚀 CÓMO EJECUTAR LA APLICACIÓN
═══════════════════════════════════════════════════════════════════════

📍 REQUISITOS PREVIOS:
   1. Python 3.9+ instalado
   2. Node.js 16+ instalado
   3. Tu modelo YOLOv8 entrenado (archivo .pt)
   4. API Key de Gemini (opcional, para chat)

📍 PASO 1: Colocar tu modelo
   $ cp /ruta/a/tu/modelo.pt models/best.pt

📍 PASO 2: Configurar Gemini (opcional pero recomendado)
   $ nano backend/.env
   # Añadir: GEMINI_API_KEY=tu_api_key_aqui
   # Obtén tu key GRATIS: https://makersuite.google.com/app/apikey

📍 PASO 3: Ejecutar
   $ ./start_all.sh

   O manualmente:
   Terminal 1: ./start_backend.sh
   Terminal 2: ./start_frontend.sh

📍 PASO 4: Abrir navegador
   http://localhost:5173

═══════════════════════════════════════════════════════════════════════
  🐛 SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════

❌ "Modelo no encontrado"
   → Verifica que models/best.pt existe
   → El archivo DEBE llamarse exactamente "best.pt"

❌ "GEMINI_API_KEY no encontrada"
   → Crea backend/.env y añade tu API key
   → El chat funcionará sin esto pero con error

❌ "No se pudo acceder a la cámara"
   → Permite acceso en configuración del navegador
   → O usa botón para subir archivo

❌ Error instalando PyTorch
   → Usa versión CPU: pip install torch --index-url https://download.pytorch.org/whl/cpu

❌ "Port 8000 already in use"
   → Mata proceso: lsof -ti:8000 | xargs kill -9

❌ Frontend no conecta con backend
   → Verifica backend en http://localhost:8000
   → Revisa CORS en backend/main.py
